# Nail Inventory 

*Projeto em desenvolvimento.*

Sistema web para o gerenciamento de inventário pessoal de esmaltes, focado no controle de datas de vencimento e organização visual do catálogo.

## Stack Tecnológico

* **Backend:** C#, ASP.NET Core Web API
* **Frontend:** Angular, TypeScript
* **Banco de Dados:** TiDB (Compatível com MySQL)
