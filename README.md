# Nail Inventory

Projeto em desenvolvimento.

Sistema web para gerenciamento de inventário pessoal de esmaltes, desenvolvido para facilitar a organização da coleção, consulta dos produtos e controle das datas de vencimento.

## Funcionalidades

- Cadastro, edição e exclusão de esmaltes
- Busca por nome ou marca
- Filtros por marca e vencimento
- Ordenação por data de vencimento
- Exibição de imagens dos esmaltes
- Contagem de esmaltes, marcas e itens vencidos
- Destaque visual para esmaltes vencidos e próximos do vencimento

## Stack Tecnológico

- C#
- ASP.NET Core Web API
- Entity Framework Core
- Angular
- TypeScript
- SCSS
- TiDB (compatível com MySQL)

## Desenvolvimento

O projeto está sendo desenvolvido como um projeto pessoal para prática e aprimoramento de conhecimentos em desenvolvimento web full-stack.

A implementação e a definição da identidade visual da aplicação contam com auxílio do ChatGPT, utilizado como ferramenta de apoio durante o desenvolvimento, especialmente na elaboração e refinamento de estilos, layout e componentes da interface.
